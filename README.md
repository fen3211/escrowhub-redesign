# EscrowHub — редизайн витрины цифровых товаров

Интерактивный UX/UI-концепт маркетплейса EscrowHub.online в эстетике Shop из Refero Styles: светлый холодный холст, белые карточки с мягкой глубиной, крупные товарные обложки, pill-контролы и один фиолетовый акцент.

## Как открыть

Откройте `index.html` в браузере. Для корректных относительных путей удобнее локальный сервер:

```bash
python -m http.server 8123
```

и затем `http://127.0.0.1:8123/index.html`.

## Что внутри

- `index.html` — витрина: поиск, категории, товарная сетка, пополнение сервисов, эскроу, FAQ.
- `catalog.html` — каталог с фильтрами, сортировкой, активными чипами и пустым состоянием; на мобильном фильтры открываются bottom sheet.
- `product.html?id=spotify` — карточка товара, продавец, условия, покупка, чат и оформление демо-сделки.
- `orders.html` — кабинет покупателя: стадии сделки, подтверждение получения, спор.
- `seller.html` — кабинет продавца: обзор, объявления, заказы, кошелёк.
- `create.html` — размещение объявления с живым превью (`?edit=spotify` — заполненный пример).
- `404.html` — локализованное состояние ошибки.
- `case.html` — дизайн-кейс: аудит, направление, экраны, решения и границы прототипа.
- `states.html` — дизайн-система: токены, типографика, контролы, обложки, формы и состояния.
- `deliverables/screenshots/` — финальные скриншоты 1440 и 390, включая состояния интерфейса.

## Дизайн-решения

- Токены: `#5433eb` — единственный акцент; `#f2f4f5` — фон; белые поверхности без рамок; `#ebebeb` — hairline-разделители.
- Карточки — 28 px, изображения — 20 px, контролы — pill. Мягкие двухслойные тени; без градиентов и декоративных пятен в UI.
- Шрифт Inter 400–600: легальная замена GT Standard, кириллица, компактный трекинг. Основной текст 16 px, заголовки не тяжелее 600.
- Товарные обложки — собственная графическая система с брендовыми логотипами и цветами товаров; случайные стоковые фото не используются.
- Все правила эскроу (0% комиссии, спор 72 часа, автозакрытие 24 часа) соответствуют публичному пользовательскому соглашению сервиса.

## Демо-границы

Прототип не подключён к реальному бэкенду, авторизации, оплате и сообщениям. Заказы, баланс, сообщения и публикация объявлений демонстрируют состояния интерфейса и не отправляют данные. Цены и названия товаров взяты с публичных страниц EscrowHub.online; сток, часть подписей и демо-заказы нормализованы для показа. Рейтинг 5.0 при нуле отзывов не переносился; продавец EWC обозначен как новый.

Исходная версия до переделки сохранена в `backup/pre-refero-2026-10-26/`.
